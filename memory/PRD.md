# Calm & Chaos — PRD

## Original problem statement
A familiar home for an overwhelmed but clever adult goblin. Greeted → grounded → able to think. ONE engine connected to brain dumps, training, calendar, budget, food, patterns.

## Architecture
- React (CRA + craco) + Tailwind + Spectral/Manrope
- FastAPI + MongoDB (Motor)
- LLM: gpt-5.2 via Emergent universal key (single-call per message)
- Gemini Nano Banana (gemini-3.1-flash-image-preview) for character-consistent goblin sprite generation
- Google Calendar OAuth (single-user, working)
- Notion source via integration token
- PWA-ready

## Personas
- Em — single user. Android. No auth.

## Implemented
- v1 → v1.3: core surface, tone constitution, single-call chat, PWA bits
- v1.4: "Discuss with goblin" buttons + evening check-in
- v1.5 (2026-05-22): **the goblin lives on the home page**
  - 4 sprites in `/app/frontend/public/`: `goblin.png` (midday, original ref), `goblin-morning.png`, `goblin-evening.png`, `goblin-late_night.png` — all character-consistent, generated by Nano Banana from Em's ChatGPT reference image
  - `<Goblin>` component on Home with:
    - breathing animation (4.2s scale loop)
    - subtle sway (9s rotation loop)
    - random blink every 5–12s (140ms eye-bar overlay)
    - time-of-day mood: swaps sprite + applies CSS filter (warm/neutral/amber/cool)
    - soft amber radial glow behind the goblin to bed her into the room
  - Hidden on very small screens to keep greeting readable
  - Sprite-generation script: `/app/scripts/gen_goblin_moods.py` — rerun any time to regenerate poses
